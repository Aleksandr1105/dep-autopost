# «Да, это правда» — автопубликация

Бот публикует посты канала по расписанию. Запускает его GitHub Actions: компьютер для этого не нужен.

- `week-ГГГГ-ММ-ДД.json.enc` — посты недели, **зашифрованы**.
- `cards/*.png.enc` — карточки «Факт дня» и «В этот день», **зашифрованы**.
- `public_key.pem` — открытый ключ: им шифруют (`python crypto_box.py encrypt файлы…`), расшифровать им нельзя.
- `crypto_box.py` — шифрование; бот расшифровывает посты только в момент запуска, ключом из секрета `DEP_KEY`.
- `sent.json` — что уже отправлено. Его ведёт сам скрипт, руками не трогать.
- `post_due.py` — публикует посты, время которых подошло.
- `tools/render_cards.py` — рисует карточки из поля `card_data` файла недели (шрифты Unbounded и Golos Text в `tools/fonts`, лицензия OFL).
- `tools/check_week.py` и `.github/workflows/check.yml` — при загрузке недели GitHub сам скачивает все фото и проверяет посты; если что-то не так, приходит письмо.
- `.github/workflows/post.yml` — расписание запусков.

Секреты (Settings → Secrets and variables → Actions):
- `BOT_TOKEN` — токен бота от @BotFather;
- `CHANNEL` — `@da_eto_pravda`;
- `DEP_KEY` — закрытый ключ для расшифровки постов (весь текст файла, вместе со строками BEGIN/END).

Бот должен быть админом канала с правом публиковать сообщения.

**Добавить неделю:** зашифровать `week-….json` и карточки (`python crypto_box.py encrypt week-….json cards/*.png`) и положить `.enc`-файлы в репозиторий.

**Проверить вручную:** вкладка Actions → «Публикация постов» → Run workflow.

Пост уходит в своё время, задержка до нескольких минут. Если GitHub задержал основной запуск, через 20 минут после слота срабатывает запасной. Пост, опоздавший больше чем на 90 минут, не публикуется и отмечается в `sent.json` как пропущенный.
